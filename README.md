# 五行精纪注释技能包（禄命法 · 八科分断）

以《五行精纪》为底本的禄命法命理技能包：输入四柱八字，以**年柱纳音为体**，八科分断纳音、干支、三元、吉神、凶神、六亲、健康、大运，判断命局根基与吉凶贵贱。与子平日主旺衰派不同，本技能包走【年命纳音 + 禄命身三命 + 神煞贵格】旧框架。

## 核心特点

- **八科分断**：纳音体用、干支合化、三元三命、吉神贵格、凶神灾煞、六亲性情、健康寿夭、大运岁运，各成一科、各司其职。
- **年柱纳音为体**：全包以年命纳音定身，看他柱生克（生入吉 / 克入鬼）、就位、互换生旺死绝。
- **断法可复现**：每科含「断法步骤 + 规则集（带卷期出处）+ 失效场景/边界」，规则均从《五行精纪》原文与命例提取，不臆造。
- **前置依赖明确**：问任何一科，都先过 `wuxing-nayin` 定年命纳音，再入本技；学科间可交叉协同（如吉凶交集需多技并断）。
